Doubt Together (Co-op)
======================

Two-player co-op for Shadows of Doubt over Steam: one player hosts their sandbox world,
a friend joins it, and both work the same cases in the same city - the same evidence,
the same citizens, the same clock. Money and inventory stay per player.

Set up once (both players):

1. Subscribe to this item on the Steam Workshop.
2. Steam > Shadows of Doubt > Properties > Launch options: paste the one line for your
   system from LAUNCH.txt (Windows and Linux/Proton lines are both in there).
3. Start the game. The first start takes a few minutes longer while the loader prepares
   itself - that is normal, let it finish.

Play:

- Host: load or start a SANDBOX save, press F11 (or use the Host Co-op button in the main menu).
- Friend: the main menu shows the host as "Join <name>"; or right-click the host in the
  Steam friends list > "Join game". Wait a minute: the host's world transfers and loads.
- Ctrl+Delete leaves the session. Story mode is not supported.
- Both players need this mod in the same version; the game tells you if they differ.

Privacy: everything runs peer-to-peer between the two of you over Steam, no servers.
Your partner sees your Steam name, your character and what you do in the shared city.

Trouble? BepInEx/sodcoop.log in the game folder tells what happened. Source, bug reports
and updates: https://github.com/0xsimsch/mp_sod  (GPL-3.0-or-later).
